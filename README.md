# Chicago Crime and Arrest Analysis

## Overview

This project analyzes relationships between crime incidents and arrest patterns using large-scale Chicago crime and arrest datasets. The project was developed as part of a Data Mining course and focuses on identifying trends, demographic relationships, and crime-related patterns through data cleaning, preprocessing, and analytical visualization techniques.

The project combines multiple datasets and explores how factors such as charge types, race, and crime characteristics relate to arrest trends and crime patterns.

## Research Focus

The primary goals of the project included:

* Exploring relationships between race and charge types
* Analyzing crime and arrest trends
* Cleaning and preprocessing large real-world datasets
* Merging crime and arrest data for analysis
* Visualizing meaningful patterns within the data

## Datasets Used

The project utilized:

* Chicago Crime Data
* Chicago Arrest Data

The datasets were filtered and cleaned to focus on relevant records, including 2024-specific entries for portions of the analysis.
